# 議事録・メモ

## 決定事項

- 技術スタックは**案2（Python ＋ React）**にする。
- フロントエンドは **React（Vite）**にする（Next.js は採用しない）。
  - 理由：バックエンドを FastAPI にしたので、Next.js の強み（サーバー機能・SEO）を使う場面がほとんどなく、
    フロントとバックの分離のルールを守る手間だけが残るため。覚えることも少なく、
    「スケジュールに追われるよりも理解を優先」というチームの方針に合う。
