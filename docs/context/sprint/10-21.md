# 話したこと：issueの立て方について

- githubに上げるのは、tasks.mdを元にして誰かが行う。
- issueの理解をした上で進める場合は、自分の環境で一覧化をした上で、突合するのも手。

- 進め方の言語化をすると良い。
- 「一覧化」の認識がずれている可能性がある。言語化をして認識を合わせておく。

---

手順

1. 各々の担当範囲やドキュメントを詰めて、mainを最新状態にする。
2. （任意）tasks.mdを元に、自分の担当に関わるタスクと、イシューとしてのまとまりを整理させる（ドキュメント化やgithubに上げるのではなく、自分の環境で行う）
3. （任意）イシューテンプレをブラッシュアップ。
4. githubに挙げるissueは、tasks.mdとイシューテンプレを元に、`taskstoissues`スキルを活用して誰かが一括で担う。
