# Quickstart: spec 005（アルバム）の通しの確認

spec 005 ができているかを、手で通して確かめる手順。作り込みの最後の通しのデモと、E2E テスト（Playwright）の元にする。
起動のしかた（`docker compose up -d`、マイグレーション、初期データ、開発用のユーザー切り替え、まとめの確かめ方）は
[spec 001 の quickstart.md](../001-family-priority-report/quickstart.md) と同じ。
API の形は [contracts/api.md](./contracts/api.md)、テーブルは [data-model.md](./data-model.md) を見る。

## 用意するもの

- spec 001 の quickstart の「起動」まで終わっていること
- 初期データ（`python -m app.seed`）に、開示設定の「アルバム」（見せる）が入っていること
- 確かめる写真は、**架空の写真**（風景や、顔の写っていない物など）を使う：JPG（縦向きに撮ったものを 1 枚含める）、PNG、PDF を名前だけ `.jpg` に変えたもの
- 入居者 A の家族アカウント（佐藤さん）、入居者 B の家族アカウント、職員（介護職員・生活相談員）を開発用のユーザー切り替えで使う

## デモ（SC-008）

職員が写真を載せる → 家族が電話をせずにアルバムでその写真を見る、までを、アプリだけで見せる（1〜6 の流れ）。
