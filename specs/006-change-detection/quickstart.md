# Quickstart: spec 006 の通しの確認

変化の検知（E）ができているかを、手で通して確かめる手順。テストシナリオ（`docs/テスト設計書.md`）の元にする。
API は [contracts/api.md](./contracts/api.md)、テーブルは [data-model.md](./data-model.md)、決まりの数え方は [research.md R-02](./research.md) を見る。

## 用意

```bash
docker compose up -d
docker compose exec backend alembic upgrade head
docker compose exec backend python -m app.seed      # 決まり 3 つ（すべてオン）と、架空の入居者・職員・記録が入る
```

- 開発用のユーザー切り替え（spec 001 R-02）で、介護職員・事務員・生活相談員・家族を切り替えて確かめる。
- 日付は日本時間。「昨日」「今日」は、初期データを入れた日を基準にする。

## 通しの確認（US1・US2）

| # | だれで | すること | こうなれば OK | spec |
|---|---|---|---|---|
| 1 | 介護職員 | 架空の入居者「佐藤 文江」に、昨日の夜ごはん「少し（2割）」を記録しておき、今日の朝ごはん「食べていない」を記録する | 入居者一覧を開き直すと「⚠️ いつもと違う様子」が付き、一覧の上に「確かめていない目印：1 件」 | US1 シナリオ 1・SC-001 |
| 2 | 介護職員 | 「佐藤 文江」を開く | 「食事量：昨日の夜ごはんから 2 食続けて、少し以下」と、もとの記録（日付・食事区分・値）、「気になるときは、看護職員・生活相談員に相談してください。」が出る。医療の言葉はない | US1 シナリオ 2・6 |
| 3 | 介護職員 | タブレットの画面を見る | 通知・音・画面を遮る表示は出ていない | US1 シナリオ 5・SC-004 |
| 4 | 介護職員 | 「確かめた」を押し、「本人は元気。夕食を様子見」と書く | 目印が「確かめ済み」の見た目になり、件数が 0 件になる | US2 シナリオ 1 |
| 5 | リーダー | 「佐藤 文江」を開く | 確かめた職員・日時・ひとことが見える | US2 シナリオ 2 |
| 6 | 介護職員 | 今日の昼ごはん「少し」を記録する | 目印が「まだ確かめていない」に戻り、「3 食続けて」になる | US2 シナリオ 3 |
| 7 | 介護職員 | 今日の夜ごはん「ほぼ全部」を記録する | 目印が消え、入居者を開くと過去の目印として、付いた日・消えた日・確かめた職員・ひとことが並ぶ | US1 シナリオ 4・US2 シナリオ 4 |

## ぶつかる場面・守りの確認

| すること | こうなれば OK | spec |
|---|---|---|
| 夜ごはん「食事なし」・朝ごはん「食事なし」を続けて記録する | 目印は付かない | US1 シナリオ 3・Edge Cases |
| 昼ごはん「少し」のあと、おやつ「食べていない」を記録する | 目印は付かない（夜ごはんで決まる） | US1 シナリオ 3a |
| 機嫌：月「元気がない」・火 未記録・水「元気がない」の記録を入れる | 目印が付く | Edge Cases |
| 機嫌：月「元気がない」・火〜木 未記録・金「元気がない」の記録を入れる | 目印は付かない | Edge Cases |
| 目印のもとになった今日の記録を取り消す | 当てはまらなくなれば目印が消える | Edge Cases |
| 眠りを非開示にした状態で、眠り「あまり眠れなかった」を 2 日続ける | 職員の画面には目印が付く。家族の連絡帳には眠りも目印も出ない | Edge Cases・FR-007 |
| 2 つの決まりに同時に当てはまる記録を入れる | 一覧の目印は 1 つ。開くと 2 つの決まりが並ぶ。件数は 1 件 | Edge Cases |
| 事務員で入居者一覧（`/api/staff/residents`）を開く | 403（職員の画面は開けない。spec 001） | FR-006 |
| 事務員・家族で、目印の API（`/api/staff/residents/{id}/change-flags`）を直接呼ぶ | 403 | FR-006 |
| 家族で連絡帳・お知らせを開き、問い合わせ AI に「最近いつもと違いますか？」と聞く | 目印は出ない | FR-007・SC-005 |
| 2 人の職員がほぼ同時に「確かめた」を押す | 後の人には「ほかの職員が確かめました」 | Edge Cases |
| ひとことに `<script>alert(1)</script>` と書く | 文字のまま表示され、実行されない | FR-013 |
| ログ（`docker compose logs backend`）を、入居者の氏名・ひとことで探す | 出てこない | FR-014 |

## 決まりの設定（US3）

| # | だれで | すること | こうなれば OK | spec |
|---|---|---|---|---|
| 1 | 生活相談員 | 管理画面の「変化の目印」を開く | 決まり 3 つと、それぞれのオン／オフ（すべてオン）が出る | US3 シナリオ 1 |
| 2 | 生活相談員 | 「眠り：2 日続けて、あまり眠れなかった」をオフにし、眠り「あまり眠れなかった」を 2 日続ける | 目印は付かない。すでに付いていた眠りの目印は消える | US3 シナリオ 2・R-07 |
| 3 | 施設長 | 変更履歴を開く | いつ・誰が・どの決まりを変えたかが出る | US3 シナリオ 3 |
| 4 | 介護職員 | 管理画面の「変化の目印」を開こうとする | 開けない（403） | FR-011 |
